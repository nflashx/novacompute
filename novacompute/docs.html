Introduction

The NovaCompute API gives you a single endpoint for 12+ frontier models — Claude, GPT, DeepSeek, Kimi, Mistral, Mercury, GLM and Qwen. Requests are auto-routed to the fastest healthy provider, and billing is per token.

Base URL: https://api.novacompute.io/v1

Quick Start

  1. Create an API key in the Dashboard → API Keys.
  2. Export it as an environment variable: NOVA_API_KEY
  3. Make your first request with cURL or Python below.
curl https://api.novacompute.io/v1/chat/completions \
  -H "Authorization: Bearer $NOVA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "model": "glm-5.3-flash",
  "messages": [{ "role": "user", "content": "Hello, Nova!" }]
}'
from openai import OpenAI
import os

client = OpenAI(
    base_url="https://api.novacompute.io/v1",
    api_key=os.environ["NOVA_API_KEY"],
)

response = client.chat.completions.create(
    model="glm-5.3-flash",
    messages=[{"role": "user", "content": "Hello, Nova!"}],
)

print(response.choices[0].message.content)

Authentication

All API requests are authenticated with a Bearer token in the Authorization header. Create and manage keys in the dashboard. 

Authorization: Bearer $NOVA_API_KEY
Never expose API keys in client-side code, browsers, or public repositories. If a key leaks, delete it in the dashboard and create a new one.

Create chat completion

POST https://api.novacompute.io/v1/chat/completions

Request body

Parameter Type Required Description
modelstringYesModel ID, e.g. glm-5.3-flash. See the Models list.
messagesarrayYesConversation so far — objects with role (system / user / assistant) and content.
temperaturenumberNoSampling temperature 0–2. Higher is more creative. Default 1.
max_tokensintegerNoUpper bound on generated tokens for this completion.
streambooleanNoIf true, tokens are sent as server-sent events. Default false. See Streaming.

Response

{
  "id": "chatcmpl-9f2c84ab",
  "object": "chat.completion",
  "created": 1762830000,
  "model": "glm-5.3-flash",
  "choices": [
    {
      "index": 0,
      "message": { "role": "assistant", "content": "Hello! How can I help you today?" },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 9,
    "total_tokens": 21
  }
}

Streaming

Set "stream": true to receive tokens as server-sent events as they are generated. The stream terminates with a data: [DONE] line. 

data: {"id": "chatcmpl-9f2c84ab", "choices": [{"delta": {"content": "Hel"}}]}

data: {"id": "chatcmpl-9f2c84ab", "choices": [{"delta": {"content": "lo!"}}]}

data: [DONE]

Models

Pass any of these IDs in the model field.

Errors

Errors return a consistent JSON shape:

{
  "error": {
    "type": "rate_limit_error",
    "code": "rate_limit_exceeded",
    "message": "Rate limit reached: 600 requests per minute."
  }
}
Status Type Meaning
400invalid_request_errorMalformed body or missing required parameter.
401authentication_errorMissing or invalid API key.
402insufficient_balanceBalance exhausted — top up in the dashboard.
429rate_limit_errorRequests-per-minute cap hit. Retry with backoff.
500 / 503server_errorUpstream issue — not billed. Auto-Routing usually retries for you.
