SYSTEM ONE

Decision models, not chat.

These models answer typed questions about a piece of text and return a calibrated probability for every option. Use them for routing, triage, classification and scoring — for free-form text, use the chat models instead.

Call a decision model

Send one request to POST /v1/systemone with the text and the questions you want answered. Every question is scored in the same request. 

curl https://novarouter.cc.cd/v1/systemone \
  -H "Authorization: Bearer $NOVA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "openjev-0.1",
    "state": "I was charged twice and support has not replied for three days.",
    "questions": {
      "department": {
        "type": "choice",
        "instructions": "Which team should handle this",
        "criteria": {
          "billing": "Payment or subscription issues",
          "technical": "Bugs or integration problems"
        }
      },
      "urgent": {
        "type": "noul",
        "instructions": "The message conveys urgency"
      }
    }
  }'

Response: answers.<question>.choice (or score / noul) plus a probability map and confidence.
